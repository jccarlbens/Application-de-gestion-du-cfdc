# `exploration/` — la recherche brute, gardée telle qu'elle est arrivée

Tout ce que vous avez rassemblé avant de décider : un vidage de recherche, la documentation d'un concurrent, des notes de remue-méninges, la longue réponse d'un modèle à une question ouverte.

**Deux règles.**

**Gardé tel quel, jamais rangé.** La valeur tient précisément à ce que ce n'est pas édité. Une fois poli, cela devient un document qui *a l'air* décidé, et un lecteur ne peut plus distinguer une preuve d'une supposition.

**Jamais cité comme une décision.** Rien dans `PRD.md`, `SOLUTION_DESIGN.md` ni dans une user story ne peut pointer ici pour justifier un choix. Une décision vit dans le document qui en est propriétaire — `SOLUTION_DESIGN.md` §14 pour une décision d'architecture, avec ses alternatives rejetées. Si quelque chose ici est porteur, promouvez-le d'abord en véritable décision.

Supprimez un fichier une fois qu'il a été entièrement absorbé dans une décision, ou gardez-le comme provenance. L'un ou l'autre convient. Le traiter comme canonique, non.
